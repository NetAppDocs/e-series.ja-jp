= Eシリーズでファイルシステムを作成する - Linux（NVMe over RoCE）
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
RHEL 9、RHEL 10、SLES 15、およびSLES 16では、ネイティブnvmeデバイス上にファイルシステムを作成し、そのファイルシステムをマウントします。

.作業を開始する前に
link:nvme-roce-access-physical-targets-concept.html["ホストからEシリーズターゲットのNVMeボリュームへのアクセス"]タスクを完了して、NVMeデバイスが適切に設定され、アクセス可能であることを確認してください。

.手順
. 場所を使用して、目的のNVMeデバイス用のパーティションにファイルシステムを作成します `/dev/disk/by-id/nvme-eui.[id#]`。
+
ファイルシステムの作成方法は、選択したファイルシステムによって異なります。この例は 'ext4 ファイル・システムを作成する方法を示しています

+
[listing]
----
# mkfs.ext4 /dev/disk/by-id/nvme-eui.000082dd5c05d39300a0980000a52225
mke2fs 1.42.11 (22-Oct-2019)
Creating filesystem with 2620928 4k blocks and 655360 inodes
Filesystem UUID: 97f987e9-47b8-47f7-b434-bf3ebbe826d0
Superblock backups stored on blocks:
        32768, 98304, 163840, 229376, 294912, 819200, 884736, 1605632

Allocating group tables: done
Writing inode tables: done
Creating journal (32768 blocks): done
Writing superblocks and filesystem accounting information: done
----
. 新しいデバイスをマウントするフォルダを作成します。
+
[listing]
----
# mkdir /mnt/ext4
----
. デバイスをマウントします。
+
[listing]
----
# mount /dev/disk/by-id/nvme-eui.000082dd5c05d39300a0980000a52225 /mnt/ext4
----


.次の手順
ファイルシステムを作成したら、link:nvme-roce-worksheet-for-concept.html["NVMe over RoCEの設定情報を記録してください。"]。
