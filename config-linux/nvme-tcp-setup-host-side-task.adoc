= EシリーズLinuxホストでNVMe over TCPイニシエータをセットアップする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
TCP環境におけるNVMeイニシエータの設定には、nvme-cliパッケージのインストールと設定、イニシエータIPアドレスの設定、およびホスト上でのNVMe-oFレイヤーの設定が含まれます。

.作業を開始する前に
最新の互換性のあるRHEL 9、RHEL 10、SLES 15、またはSLES 16サービスパックオペレーティングシステムを実行している必要があります。最新の要件の完全なリストについては、 https://mysupport.netapp.com/matrix["NetApp Interoperability Matrix Tool で確認できます"^]を参照してください。

.手順
. HCA にインボックスのイーサネット ドライバーを使用している場合は、次の手順で `nvme-cli`パッケージをインストールします。
+
*SLES 15またはSLES 16*

+
[listing]
----

# zypper install nvme-cli
----
+
* RHEL 9 および RHEL 10 *

+
[listing]
----

# yum install nvme-cli
----
+
NVIDIA HCA を使用していて、外部 DOCA ドライバーを使用したい場合は、この環境への適切なインストール方法について link:https://developer.nvidia.com/doca-downloads["NVIDIAのドキュメント"] を参照してください。

. RHEL 9 の場合、ネットワークスクリプトをインストールします：
+
* RHEL 9*

+
[listing]
----
# yum install NetworkManager-initscripts-updown
----
+

NOTE: RHEL 10 ではネットワークスクリプトは利用できません。

. ホストのNQNを取得します。アレイに対してホストを設定する際に使用します。
+
[listing]
----
# cat /etc/nvme/hostnqn
----
. TCP経由でNVMeを接続するために使用するイーサネットポートに、IPv4 IPアドレスを設定します。各ネットワークインターフェースごとに、そのインターフェースのさまざまな変数を含む設定スクリプトを作成します。
+
この手順で使用する変数は、サーバハードウェアとネットワーク環境に基づいています。変数には 'IPADDR' と 'gateway' が含まれます次に、 SLES および RHEL の例を示します。

+
*SLES 15*

+
次の内容を含むサンプルファイルを作成します `/etc/sysconfig/network/ifcfg-eth4`。

+
[listing]
----
BOOTPROTO='static'
BROADCAST=
ETHTOOL_OPTIONS=
IPADDR='192.168.1.87/24'
GATEWAY='192.168.1.1'
MTU=9000
NAME='<adapter name>'
NETWORK=
REMOTE_IPADDR=
STARTMODE='auto'
----
+
次に'/etc/sysconfig/network/ifcfg-eth5`のサンプルファイルを作成します

+
[listing]
----
BOOTPROTO='static'
BROADCAST=
ETHTOOL_OPTIONS=
IPADDR='192.168.2.87/24'
GATEWAY='192.168.2.1'
MTU=9000
NAME='<adapter name>'
NETWORK=
REMOTE_IPADDR=
STARTMODE='auto'
----
+
*RHEL 9、RHEL 10、またはSLES 16*

+
を使用します `nmtui` 接続を活動化および編集するためのツール。以下はサンプルファイルです `/etc/NetworkManager/system-connections/eth4.nmconnection` ツールは次のものを生成します。

+
[listing]
----

[connection]
id=eth4
uuid=<unique uuid>
type=ethernet
interface-name=eth4

[ethernet]
mtu=9000

[ipv4]
address1=192.168.1.87/24
method=manual

[ipv6]
addr-gen-mode=default
method=auto

[proxy]
----
+
以下はサンプルファイルです `/etc/NetworkManager/system-connections/eth5.nmconnection` ツールは次のものを生成します。

+
[listing]
----

[connection]
id=eth5
uuid=<unique uuid>
type=ethernet
interface-name=eth5

[ethernet]
mtu=9000

[ipv4]
address1=192.168.2.87/24
method=manual

[ipv6]
addr-gen-mode=default
method=auto

[proxy]
----
. ネットワークインターフェイスを有効にします。
+
[listing]
----

# nmcli connection up eth4
# nmcli connection up eth5
----
. ホスト上でNVMe-oFレイヤーを設定します。以下のファイルを `/etc/modules-load.d/`の下に作成して、 `nvme_tcp`カーネル モジュールをロードし、再起動後もカーネル モジュールが常に有効になるようにします：
+
[listing]
----

# cat /etc/modules-load.d/nvme_tcp.conf
  nvme_tcp
----
. ホストをリブートします。
+
.. または、次のコマンドを実行することで、再起動せずに `nvme_tcp`カーネル モジュールをロードすることもできます：
+
[listing]
----

# modprobe nvme_tcp
----


.  `nvme_tcp`カーネルモジュールがロードされていることを確認するには、次のコマンドを実行します。
+
[listing]
----
# lsmod | grep nvme
nvme_tcp               45056  0
nvme_fabrics           24576  1 nvme_tcp
nvme_core             114688  5 nvme_tcp,nvme_fabrics
t10_pi                 16384  2 sd_mod,nvme_core
----
+
.次の手順
ホスト上でNVMe over TCPイニシエータを設定した後、link:nvme-tcp-configure-storage-connections-task.html["TCP経由のNVMeポート設定を構成する"]。
