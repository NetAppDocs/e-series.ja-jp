= EF50およびEF80ストレージシステムのI/Oモジュールのメンテナンスについて説明します。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
EF50およびEF80ストレージシステムは、I/Oモジュールの交換やアップグレードにおいて柔軟性を提供し、ネットワーク接続性とパフォーマンスの向上、およびストレージ容量の増強を実現します。

* link:io-module-replace.html["I/O モジュールを交換する"]
+
ストレージ システムの I/O モジュールに障害が発生した場合は、同じタイプの I/O モジュールと交換することで、ストレージ システムを最適な動作状態に復元できます。

* link:io-module-upgrade.html["I/O モジュールをアップグレードする"]
+
ストレージシステムのI/Oモジュールをアップグレードすることで、ホスト ポート数を増やしてネットワーク接続性を向上させたり、システムのデータトラフィック処理能力を拡張したり、SAS拡張シェルフを接続したりすることができます。

+

NOTE: SAS拡張I/OモジュールはSANtricity 12.10以降を実行しているストレージシステムでサポートされています。
