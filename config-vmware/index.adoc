= EシリーズにおけるVMwareホスト構成のクイックスタート
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージアレイのインストールと SANtricity System Manager へのアクセスに関する VMware Express 方式は、Eシリーズ ストレージ システムを使用するスタンドアロンの VMware ホストをセットアップするのに適しています。これは、最小限の判断ポイントでストレージ システムをできるだけ迅速に稼働させることを目的として設計されています。



[[procedure-overview]]
== 手順の概要

クイック方式で実行する手順は次のとおりです。も参照してください link:understand-vmware-workflow-concept.html["VMware のワークフロー"]。

. 次のいずれかの通信環境を設定します。
+
** link:nvme-fc-perform-specific-task.html["NVMe over Fibre Channel の 2 つのプロトコルがサポート"]
** link:fc-perform-specific-task.html["Fibre Channel（FCP）"]
** link:iscsi-perform-specific-task.html["iSCSI"]
** link:sas-perform-specific-task.html["（ SAS ）。"]
** link:nvme-roce-perform-specific-task.html["NVMe over RoCE"]
** link:nvme-tcp-perform-specific-task.html["NVMe over TCP"]


. ストレージアレイに論理ボリュームを作成します。
. ボリュームがデータホストに表示されるようにします。
